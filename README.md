# react-tic-tac-toe-194635-194644

This workspace contains the Tic Tac Toe React frontend in `tic_tac_toe_frontend/`.

Run:
- npm install
- npm start

Environment variables used by the app (optional):
- REACT_APP_API_BASE
- REACT_APP_BACKEND_URL
- REACT_APP_FRONTEND_URL
- REACT_APP_WS_URL
- REACT_APP_NODE_ENV
- REACT_APP_NEXT_TELEMETRY_DISABLED
- REACT_APP_ENABLE_SOURCE_MAPS
- REACT_APP_PORT
- REACT_APP_TRUST_PROXY
- REACT_APP_LOG_LEVEL
- REACT_APP_HEALTHCHECK_PATH
- REACT_APP_FEATURE_FLAGS

Feature flag example:
- Set REACT_APP_FEATURE_FLAGS=dark_default to start in dark theme.
